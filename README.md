# ToolPilot AI — Static Website V1

Responsive static website starter for a global English-language AI software directory.

## Files
- `index.html` — homepage, tool directory, search and category filters
- `styles.css` — responsive styling
- `script.js` — interactive filters, mobile menu and demo newsletter behavior
- `disclosure.html` — starter affiliate disclosure
- `privacy.html` — starter privacy page

## Run
Open `index.html` in a browser. No build tools or server are required.

## Free hosting
Publish this folder using GitHub Pages, Cloudflare Pages, or Netlify static hosting. A custom domain is optional; use the free platform URL to test first.

## Before launch
1. ToolPilot AI is a working name; check domain and trademark availability before investing in branding.
2. Test the Systeme.io affiliate link in a private/incognito browser and confirm referral tracking in your account. The supplied affiliate ID is retained; the `/no` locale prefix was removed for a global-facing URL.
3. The guide cards are topic placeholders, not full articles. Publish original, useful articles before expecting SEO traffic.
4. Connect the newsletter form to an email provider or remove it.
5. Add real contact details and review privacy, affiliate, cookie, and legal requirements.
6. Verify current provider features and prices before making specific claims.

## Limitations
No database, CMS, user login, email capture, analytics, or automatic price updates. Listings are manually maintained.
